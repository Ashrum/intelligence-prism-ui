## 12 验证协议与验收矩阵

### 12.1 验证层和材料

| 验证层 | 可证明什么 | 不可据此证明什么 |
| --- | --- | --- |
| 设计走查 | 目标、流程、字段及异常分支自洽 | 已实现或真实可用 |
| 工程与浏览器检查 | 相应版本的接口、权限、幂等、数据及界面行为 | 教师完成工作或学生学习收益 |
| 可用性验证 | 使用者理解、完成任务、误解和新增负担 | 真实写入、因果教学效果 |
| 真实教学试点 | 能否融入正常工作、实际执行、证据可信性及有条件变化 | 仅凭前后差异归因教师或策略、普遍适用 |
| 正式教育与测量验证 | 按预设方案回答与非 AI 基线的学习、保持、测量和诊断问题 | 未测人群/情境自动继承效果或 L0 准入 |

材料包包含真实有效任教关系内同一教师的两个班、同一学科、正在教学的目标，分别记录计划/实际进度、学生集合、任务与评分版本、截止和已有支持。合成走查可用第 5.4 节例子，真实试点不强套。准备正常推进、需调整、未知，独立/提示/订正/新题，缺测/待复核/撤回/转班/未到期，非试卷动作和既有正常检查。

每个事实源先标现有可用、需补接、不可验证。原型未实现处明确模拟，不将主持人口头补全或开发者代做算成用户完成。

### 12.2 教师核心场景

| 场景 | 用户任务 | 通过条件与应留证据 |
| --- | --- | --- |
| T01 | 打开两班概览，说明分别教到哪里、证据覆盖及下一次检查 | 范围/时间/计划/实际和来源明确；不从分数差异判教师质量；留范围快照与教师解释 |
| T02 | A 班准备辨析，B 班保留正常安排和观察 | 材料可复用，对象/时机/检查分别成立，不被动给两班加练；留编辑差异和回执 |
| T03 | 本轮证据支持继续做法，减少重复讲练 | 可保留并观察，无须补救单；一次表现不写稳定掌握或方法已验证；留决定与依据 |
| T04 | 实施重讲/提问/小组支持，复用既定作业检查 | 非试卷动作可承接，不伪造试卷；执行与证据分别到达；留实际记录与正常教学证据 |
| T05 | A 班部分未改善而调整，B 班继续 | 原轮次/对象保留，新决定可关联下一轮；不自动归因态度或教师；留未知对象 |
| T06 | 取消或转交不适用安排 | 未执行和已发生分开；正式已发布任务按原规则处理，关闭卡片不假称撤回；留回执 |
| T07 | 切换两班并遇到来源更正 | 名单不混、草稿保留原范围与版本，更新差异可查，不合格用途受阻；留版本及选择 |

### 12.6 低负担可用性与真实教学试点

参与者以日常工作语言完成 T01—T07，再由对应职责者完成 M 场景；校长、集团、区域不能全部由教师或开发者代演。记录是否准确说明事实/未知/下一步、耗时、求助、反复返回、放弃、重复录入、手填必要性、额外作业/打卡/照片/文书和继续使用意愿。

可用性首轮建立时间与负担基线，不预先宣称节省比例。必须重录已有名单/题目、强制额外测验或靠主持人代操作完成核心流程，记为待整改。人数与代表性在招募时确定，小样本走查不概括所有学校。

真实试点开始前确认学校、角色、学科、两班、周期、真实服务范围与使用授权，固定实现/来源/指标版本，先过对应合成反例，预先约定教学目标与检查。未就绪管理能力不作真实操作。教师可合理调整方案并保留差异；未到期、缺证据、无改善和取消如实记录。

结束时分别报告工作是否真实完成、负担与可信性、取得何种后续观察及下一轮决定；保留失败和正常案例。没有后续证据时仍可评价可用性，不能评价学习改善。

### 12.8 出口与留证

每项记录场景编号、阶段、验证层、版本/环境、参与角色、输入与数据类型、预期、实际步骤/回执、成果引用、观察、缺口、结论、责任与复查时间。未执行、能力未就绪未测、通过、部分通过、不通过分别标识。

**批次判定互斥规则：**①通过、部分通过、不通过只用于本批声明适用且已执行的场景；关键断言失败不能记通过。②本批不适用的能力即使全周期台账记“未测”，不计入本批通过，也不是本批失败，出口不得宣称其已验收。③本批适用但未测的场景才限制该批出口；不能为了放行事后改为不适用。适用性、执行状态、验收结论分别记录，不以一个“未测”列混合三件事。

P0 要求范围/事实/资格/版本/分母和相关反例通过；P1 要求两班正常/调整/执行/复盘及未知失败可恢复；P2 要求独立页面和交互正确，不依赖 Agent 实接；P3 通过 AG01 检验实接后的双入口一致性；P4 要求各角色真实完成本职支持并回到后续教学。浏览器覆盖桌面、窄屏、核心三主题和 Blueprint 第四主题、键盘、长内容、大名单、来源切换、辅助技术数值。用户任务、真实服务与教育效果独立留证。核心任务仍依赖研究人员代操作、存在关键范围/指标误解，或强制无必要负担未解决时，不进入对应真实教学试点；完成修复后复核该出口。

## R2-M08 默认值、模板与主持帮助的评分

关联：FC-13，T01—T07、EDU08/AG02、§12.9。

**输入 A：** 被测任务要求教师核查 A 班并保存合法安排。页面默认 A 班，模板已带入正确对象；教师自行核对、正确解释证据/未知，调整必要内容并完成任务，未得到主持人的指向性帮助。行为记录或事后核验足以证明范围理解。

**预期 A：** 可记 2；不要求为证明独立再选一次 A 班，也不强制逐项口头同意默认值。使用菜单、产品帮助或合法解释不直接降分；按钮位置另记可发现性问题。
