Agent Spec

机器可读的核心契约。视觉演示与本节冲突时，以组件规范、基础规范和固定 coss 源码的权威顺序解释，不自行补造缺失值。

字体契约 v0.2.1：页面使用语义角色；题干、完整回复与长编辑区为 16/28；状态与操作说明至少 14px。字号适配在 Prism 层完成，固定 coss 源文件不变。

Component
HeatmapChart — optional compact matrix
Source
  • Existing EChart heatmap and coss Table; docs/polar-charts.md
Contract
  • compact?: boolean = false. Opt-in grid and truncated axis labels fit 3×3 to 5×3 matrices in about 300px; cell values already render by default. Missing/zero, colours, selectedId and onSelect(id) are unchanged. Omitted or false preserves the plot options; P59 moves technical summaries into 查看数据 and formats percentages as integers.
  • Full row/column names remain in tooltips and the data table. Caller supplies labels, values, units and any sequentialColors.
Accessibility
  • Named chart, text summary and data-table keyboard alternative; EChart disables animation and resizes with container.
实现基于 Apache ECharts ↗。使用页面顶部选择器检查浅色、暖纸与深色。

组件接口与边界

数据、单位、标签、选择状态与回调由调用方提供。组件不读取学生、题库或工作流状态，不计算诊断结论。
