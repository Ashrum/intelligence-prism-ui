## 呈现与职责

- 顺序为任务身份与当前／历史标记、范围和约束、必要提示、来源和四类独立事实、版本与定位。
- 选用、读取、本轮上下文使用、成果引用分别由宿主提供。confirmed 说明具体范围；absent 只可用于宿主已确认记录覆盖完整且没有对应事件；缺记录用 unknown，不可核验用 unavailable。
- 前端不读取事件来认证真实性，不从选用、预览、读取推演其他事实。打开来源只回传 ID，例子不会改变任何证据状态。
- 展开只增加定位信息，关键未知状态在收起时也可见。expanded 为受控值；对话态与完整详情沿用同一 sources，不创建业务副本、Store、权限检查或宿主右栏。
- 历史快照不被当前结果自动替换；真实权限变化后的隐藏、清理和再次授权由宿主负责。示例不得作为生产权限验收。
- 窄容器按实际容器宽度从三列事实转为纵向，保留完整文字与键盘焦点。控件沿用当前 Prism / coss。

## 组合参照

页面下方仅使用已有基础组件和步骤进度，手动提供确认、已接收、运行、待人工、确认过期、回执不明、成功、部分完成与明确失败等示例。不新增 Runtime 状态模型或公开的确认／结果实现。

阻碍当前动作的信息优先；确认被接收后只读保留范围；未知回执只允许发出查询原执行意图，不能重复原提交；明确失败且宿主提供恢复能力才呈现重试；结果保留成功和未完成部分。示例回调从不冒充真实服务回执。
