## 0 一句话

**墨线只画结构，内容不加框；先给结论；曜彩做面，文字用字色；实色是已经发生，斜纹是还没有。**

## 1 原则

1. **结构和内容分开。** 墨线围出少量大块，块里的内容用浅线、留白和底色组织。
2. **结论先行。** 每页先给一句结论或当前状态，再放证据面板。一个面板只回答一个问题。
3. **颜色有意义。** 一种颜色在全站只表达一种意思，并且不单独表意，要配文字、符号或线型。
4. **字不压原色。** 曜彩原色只做没有文字的面和标记。
5. **斜纹表示“还没有”。** 实色表示已经发生；斜纹表示对照、剩余、未达成、没有数据。
6. **只换视觉。** 主题适配不改结构和几何（沿用 P107）。

## 2 线条与框

### 2.1 线条三级

| 级别 | 样式 | 只用于 |
|---|---|---|
| L1 结构线 | 1.5px `--line` | 页面主分区（顶栏底、左栏右、右栏卡片外框）、面板外框、面板标题下沿、标题栏（`bp-titleblock`）外框、主按钮 |
| L2 分隔线 | 1px `--border` | 面板内的行分隔、表格行、标题栏内格、输入框和下拉的默认边、次按钮、提示框（`bp-callout`）、浅色说明卡 |
| L3 无线 | 底色或留白 | 列表项、chip、状态签、记录条目；选中态用 `--accent` 底加左侧 2px 墨线 |

### 2.2 嵌套和标题

- **框最多两层**：页面主分区 → 面板。面板里不再出现 L1 框；卡片嵌在卡片里时，内层降为 L2 或去框。
- **一个标题一道线**：面板标题只用底边一道 L1。`BpSectionCard titleRule` 的尾线停用（P106 修订，见 §12）。
- **虚线只用于分组**，不做行分隔。

## 3 标识与强调

| 元素 | 规则 |
|---|---|
| 面板编号块 | 每个面板一个，放在标题左侧。无归属的页面用墨底白字；有责任方的页面用角色字色底白字（§4.4）。一屏不超过 4 个 |
| 图纸大字母、SHEET 号、刻度尺、双框 | 只用于画板和对外材料封面（§7），工作页不用 |
| 主按钮 | 墨底白字，硬阴影 3px 曜蓝 `#339FF2`。一屏一个主按钮 |
| 次按钮、筛选、输入 | L2 边，白底，无阴影 |
| 危险按钮 | 红字，L2 红边 `#E3B3B3`，放在最后，先确认 |
| 状态签 | 不加边框（§4.3） |

## 4 智能曜彩

### 4.1 三色三级

| | 原色：无字的面和标记 | 字色：文字和细线 | 浅底：大面积底 |
|---|---|---|---|
| 曜蓝 | `#339FF2` | `#0F5FA8`（白 6.52 · 浅底 5.67） | `#E3F1FD` |
| 曜紫红 | `#E0438F` | `#A8245C`（白 6.84 · 浅底 5.77） | `#FCE6F0` |
| 曜青绿 | `#C2F25B` | `#3F6309`（白 7.00 · 浅底 6.46） | `#EEFBD3` |

夜图：
- 字色用 曜蓝 `#5BB4F5`（7.57）、曜紫红 `#F48BBA`（7.53）、曜青绿 `#C2F25B`（13.15）；
- 原色可以直接做面；
- 夜图浅底的取值留到 U2 浏览器验收时定（§13 Q5）。

### 4.2 一色一义

| 颜色 | 意思 | 用在 |
|---|---|---|
| 曜蓝 | 数据、AI、可操作 | 图表主系列、链接（字色）、主按钮硬阴影、进行中、AI 来源（配文字） |
| 曜紫红 | 需要人处理 | 待确认、优先处理、受阻、新情境、低于预期 |
| 曜青绿 | 完成、确认、正向 | 已确认、高于预期、补回、荧光笔 |
| 红 `#C62828` | 错误、危险 | 真正的错误、危险操作；不和曜紫红混用 |
| 灰 | 中性、待定 | 待实施、未开始、继续观察 |

### 4.3 文字和颜色

- **字不压原色**：色块、柱、点、色带、色签前的小方块用原色；文字一律用字色级，放在白底或浅底上。所有文字对比度 ≥ 4.5，目标 ≥ 5.5。
- **状态签**：浅底加字色的药丸，无边框。一行最多一个状态签。
- **荧光笔**：曜青绿原色色带衬在墨字下面（墨字 13.65）。只用在结论句和图表注释里，一屏 1–3 处。
- **签名色带**：顶栏下一条 3px 三色带；标识前三色竖条。三色并排只出现在这里和对外材料封面。
- 不用渐变，不发光。AI 来源的三色渐变沿用现行规则，只用于真实 AI 来源，并配文字。

### 4.4 角色色

用于有责任方的页面（教研项目、学校决定、教师确认这类）：
- 教研对应曜蓝，学校对应曜紫红，教师对应曜青绿；
- 面板编号块用对应字色底加白字；
- 角色签用浅底加字色，前面放原色小方块；
- 进度条已完成部分用原色，剩余部分用同色斜纹。

无归属的页面不使用角色色。

### 4.5 用量

- 面积（截图像素）：中性色 ≥ 85%；曜彩原色和浅底合计 ≤ 10%；荧光笔和强调 ≤ 5%。U0 鲜明版实测约 3%。
- 颜色多不代表重要。一屏里最醒目的应当是结论句和主按钮。

## 5 斜纹

| 斜纹 | 意思 |
|---|---|
| 墨斜纹（`#4B5260` 线 / 白底） | 对照值、剩余、没有数据 |
| 曜紫红斜纹（字色线 / 浅底） | 未达成、未补回、低于预期、优先处理区 |
| 曜蓝斜纹 | 计划中、待批阅；教研侧未完成 |
| 曜青绿斜纹 | 待确认的达成；教师侧未完成 |

- 规格：135°，线宽 1.5px，间距 6px；斜纹块加 1px 墨框；SVG 用同参数的 `pattern`。
- **斜纹上不放字**，标签放在旁边，或加白色描边。
- 常用位置：
  - 进度条、指标条的剩余和未达成部分；
  - 对比条中的对照组（源站做法）；
  - 图表里低于预期的区间、优先处理区；
  - 没有数据的周期；
  - “数据不足”分组。

## 6 版式

| 项 | 规则 |
|---|---|
| 结论 | 页首一句，22px / 600，放在浅底说明卡里（L2 边，3px 曜蓝左条）；下一行灰字写依据和“看依据 →” |
| 面板 | 一屏 2–4 个；一个面板一个问题；内容多就拆页或折叠 |
| 字号 | 正文 14–15px；数值 KPI 30px 等宽；13px 及以下只用于注释、元信息和表头，占比 ≤ 55% |
| 等宽字 | 只给数字、编号、坐标；中文值用无衬线 |
| 宽度 | 内容最大 1120（含右栏页 1000），沿用高分辨率规则（AP22） |

## 7 装饰按场景

| 场景 | 网格纸 | 双框＋刻度尺＋SHEET 号 | 斜纹 | 签名色带 |
|---|---|---|---|---|
| 工作台页面 | 页面底，透明度降到 .045 | 不用 | 用（§5） | 顶栏一条 |
| 预览框架 | 按冻结规定 | 按冻结规定 | 用 | 不加 |
| 画板 | 页面底 | 每张图纸一次 | 用 | 可用 |
| 对外材料（PPT、印刷） | 不用 | 封面一次 | 用在图表里 | 封面、章节页用大色块 |
| 长文（规范、说明） | 不用 | 不用 | 不用 | 不用；用阅读版式 |

对外材料的“印刷版式”（白底、线宽按印刷换算、字号和留白加大、一页一图）在 U5 另出样张和说明。

## 8 图表

- 实际值：曜蓝字色线（2–2.2px）加原色数据点（1px 墨描边）；可加曜蓝浅底面。
- 预期、对照：灰虚线，或墨斜纹条。
- 关注项：曜紫红；正向：曜青绿面加墨描边。曜青绿不做细线。
- 数值标签：墨字加 4px 白描边，压在色块上也清楚。
- 不靠颜色单独区分系列，要同时配形状或线型（方、菱、圆、虚线）。

## 10 验收

每张单的 1440 走查加一项检查，用工作台 `scripts/blueprint-metric/`（`shot.mjs` 截整页、`metric.js` 量指标）：

| 指标 | 上限 | U0 鲜明版实测 |
|---|---|---|
| 墨框 / 百万像素（主区） | ≤ 5 | 学情 2.7 · 项目 4.5 |
| 墨框嵌套 | ≤ 2 层 | 2 · 1 |
| 编号块和黑底块 | 一屏 ≤ 4 个（按屏计，替代按面积计） | 达标 |
| 13px 及以下文字 | ≤ 55% | 项目 47% |
| 曜彩面积（截图像素） | ≤ 10% | 约 3% |
| 文字对比度 | 全部 ≥ 4.5 | 全部 ≥ 5.6 |

## 11 实施顺序

U2 Prism 全局层 → U3 工作台逐板块（学情 → 批阅 → 资源 → Agent → 学校管理员 → 设置与个人空间）→ U4 画板样式（`bp_common.py` 换成 v2，教研画板出 REV 0.2）→ U5 对外版式。冻结画板不回改，下次修订时跟进。每张单只换视觉。
