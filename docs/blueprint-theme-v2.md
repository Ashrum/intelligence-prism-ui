## 0 一句话

**用制图的方法表达数据：对齐、标注、尺寸、审定。墨线只画结构，曜彩只表语义，斜纹只说“还没有”。**

## 1 主题范围（取代 v2“适用”与 1.1 背景）

- 蓝图是**唯一产品主题**。浅色 / 纸张 / 深色三套只在组件站展示，不再为它们扩展新样式；核心主题输出保持不变（测试保留）。
- 夜图**暂停**：不新增夜图样式，不做夜图验收；已有夜图规则冻结在现状。
- **覆盖层冻结**：`blueprint.css` 不再新增覆盖规则；新样式写进组件本身（令牌＋变体）。改到哪个组件，就把该组件的覆盖规则迁进组件。

## 2 字号（新增，取代 v2 §6“字号”行）

| 档 | 用途 | 规格 |
|---|---|---|
| 数字 | 指标、关键数值 | 28px / 600，Geist Mono |
| 结论 | 页首结论句 | 22px / 600 |
| 正文 | 表格、说明、按钮 | 15px（表格可 14px） |
| 注释 | 元信息、坐标轴、图例、审定栏 | 12px |

不再使用 13px、16px 作为独立层级；面板标题 15px / 600。

## 3 版式（修订 v2 §2、§6）

1. **面板不加框。** 主区内面板之间用 32px 留白分隔，面板标题下一道 1px 墨线（`--line`），面板本身无外框。墨框只留给：顶栏底、主按钮、审定栏、表格外框（需要时）。
2. **8 列网格对齐。** 主区内容最大 1120px，分 8 列；内容边缘、数字列、图表起点落在列线上。产品界面**不显示**列号（列号只在画板 / 设计说明中出现）。
3. **页名。** 有页签的页面：页签行左侧常显模块名（14px 灰字，右侧一道竖分隔线）。没有页签的页面：内容顶部一行 14px 灰字「模块 · 页面」，筛选器放在同一行右侧。取代导航 REV 0.1a“一到四级不显示页面标题”中的“完全不显示”（导航画板出 REV 0.2）。
4. **结论先行（沿用 v2 §6，改写法）。** 结论句直接写在页面上，不再套浅底说明卡；关键数字用荧光笔（曜青绿原色下半高衬底，墨字）。

## 4 新增制图元素

| 元素 | 用途 | 规格 |
|---|---|---|
| **尺寸线** | 表示两个值之间的差（实际与预期、补回与未补、构成） | 1px 线，两端 6–16px 端线，引出线用 2/2 虚线；数值写在线旁，Geist Mono 13px / 600；颜色按语义（高于预期＝曜青绿字色，低于＝曜紫红字色，中性＝墨） |
| **参照号** | 把结论里的数字连到证据 | 圆圈数字 ①②③，曜蓝字色 11px / 600；结论处上标，证据处（图上尺寸线旁、指标标题旁）同号；下一行灰字说明“① 见……” |
| **引线批注** | 图上单点的说明（新情境等） | 1px 折线，终点无箭头，文字 12px 同语义色 |
| **审定栏** | 回答“结论靠不靠得住” | 1px 墨框小表，12px：数据截至 / 依据 / 得出（规则或 AI）/ 范围；放在结论右侧，占 2 列 |
| **一格一人** | 小规模个体分布（≤ 60 人） | 每人一格 30px，间距 4px，按状态排序；颜色与状态色、斜纹规则一致；配图例和人数 |
| **双段错题条** | 一根条讲两件事 | 条长＝出错率；条内紫红斜纹段＝其中再考仍错；右侧大字写仍错率 |
| **草稿斜纹边** | AI 生成、未确认的内容 | 左侧 12px 曜蓝斜纹带＋1px 曜蓝字色边框，顶部“AI 草稿 · 待你确认”标签；AI 推断的句子加 2px 曜蓝下划线；确认后换 1px 墨实线，审定栏记来源与确认人 |

## 5 颜色（取代 v2 §4.2、§4.4，修订 §12 X2–X4）

### 5.1 一色一义，只留语义

| 色 | 唯一含义 |
|---|---|
| 曜蓝 | 数据、AI、可操作（含 AI 草稿） |
| 曜紫红 | 需要人处理 |
| 曜青绿 | 完成、确认、正向 |

- **取消角色色**（教研 / 学校 / 教师不再对应三色），角色用图标或文字签区分。
- **批阅阶段色**并入语义色或改中性：收卷、AI 批阅、复核不再各占一色。

### 5.2 状态色四档（业务与系统共用）

| 档 | 字色 | 用于 |
|---|---|---|
| 错误 | 红 `#C62828` | 真正的错误、危险操作 |
| 需处理 | 曜紫红字色 `#A8245C` | 待审核、待确认、受阻、低于预期 |
| 完成 | 曜青绿字色 `#3F6309` | 已确认、可用、高于预期 |
| 中性 | 灰 `#4B5260` | 待定、未开始、已下架、继续观察 |

`#216440`（系统成功）、`#995909`（系统警告）退役。状态在列表里用**字色＋圆点**（● 实心＝当前状态，○ 空心＝失效），不再用色块标签；要人处理的行左侧加 3px 曜紫红竖线。

### 5.3 图表色板（取代 P132 六色）

收为 4 色，全部满足文字 ≥ 4.5：曜蓝字色 `#0F5FA8`、曜紫红字色 `#A8245C`、曜青绿字色 `#3F6309`、灰蓝 `#5A6B80`（白底 5.46、纸底 5.04）。墨不做数据系列，只作对照线与结构。超过 4 个系列的图改用形状区分或拆图。

## 6 斜纹（取代 v2 §5）

| 斜纹 | 唯一含义 |
|---|---|
| 同色斜纹（曜蓝 / 曜紫红 / 曜青绿） | 该语义下的“剩余 / 未达成 / 未确认” |
| 墨斜纹 | 没有数据 |

- “对照值 / 预期”不再用斜纹，改用灰虚线（线图）或浅实色（条）。
- 斜纹块用**同色 1px 细框**，不再用墨框。
- 一个面板最多一种斜纹（不含图例）。
- 规格不变：135°，线宽 1.5px，间距 6px；斜纹上不放字。

## 7 不变

主按钮墨底白字＋3px 曜蓝硬阴影（PO 2026-11-06 保留）；直角；网格纸底 .045；签名色带；Geist Mono 只给数字；字不压原色；预览框架按冻结规定。

## 8 验收（修订 v2 §10）

- 1440 主路径与画板并排对照；390 无横向滚动。
- 量法脚本只作参考：**排除** `bp-fill-*` 色块描边、图例方块后再算墨框密度（上限仍 5 / 百万像素，嵌套 ≤ 2）。
- 文字对比度全部 ≥ 4.5。

## 11 页面骨架（两种状态、三级；并入 2026-11-06）

依据：页面骨架样张 FROZEN REV 0.5，S0–S3。

**两种状态**：在主页面挑事（浏览，有导航）；打开一个对象把事做完（工作，全屏，无导航）。工作中点不到导航，流程不会丢。

| 级 | 是什么 | 骨架 |
|---|---|---|
| S1 主页面 | 从顶栏模块、左栏栏目进入 | 顶栏 52 ＋ 左栏 232（可收起 56）＋ 主区（左右 40，内容 ≤ 1120，见 §3）：页名行 52（§3 第 3 条的页名写法） → 结论行（可省）→ 一张列表（等你处理的排最前，左侧 3px 曜紫红条；其余按时间）→ 分页（页码写进网址）。不放页面标题、面包屑与图纸符号 |
| S2 子页面（全屏预览框架） | 点主页面的一行或一张面板 | 盖在主页面上，主页面不卸载；无顶栏、无左栏。上方一行 56：唯一出口“← 返回 来处”· 对象名 18（只出现一次）· 状态签 · n / N ‹ ›（主页面列表顺序）· 通知点 · 次操作 ≤ 2 · 主操作 1 · ⋯（危险操作，二次确认）。内容区左右 72、宽 1296、8 列网格，顺序固定：对象内页签（按需）→ 结论句＋审定栏 → 指标格（按需）→ 证据面板 |
| S3 再展开 | 点子页面里的一项 | 右侧展开 640（✕ / Esc 回子页面原处），或第二层纸面（索引 200 · 纸面 600 · 报告 300，“← 返回 上一层对象名”）。最多三级 |

规则：
1. 每级只有一个出口；返回回到原处，来时的那一行高亮。
2. 逐个处理用上一个 / 下一个，顺序就是主页面列表的顺序，不另摆名单、不把左栏换成名单。
3. 不设收尾行（PO 2026-11-06 取消）：下一位、下一份只走上方一行的 n / N ‹ ›；结束就用唯一出口返回。
4. 工作中只保留通知点（点开为右侧展开）与 Agent。
5. 模态只做确认和 1–3 个字段；行内展开不带操作；不在子页面里再开全屏子页面。
6. 一份数据一种呈现；不拿数量没有上限的维度（班级、人）做版面的列。

## 12 预览框架语汇（并入 2026-11-06）

依据：页面骨架样张 D1–D4，母版为对照样张 02（学情概览）。“先给结论，再给证据，最后说靠不靠得住。”

1. **四档字号** 28 数字 / 22 结论 / 15 正文与面板标题 / 12 注释（同 §2）。
2. **结论句** 22 / 600，关键数字用曜青绿荧光笔，后接 ①② 引注，指向证据图。
3. **审定栏**：数据截至、依据、得出（规则 / AI）、版本；人员类对象写来源、维护人、可改范围。
4. **指标格** = 12 标签 ＋ 28 等宽数字 ＋ 小图（构成条 / 分布小柱 / 刻度）＋ 一行说明（分子分母）。不是数字的东西（工号、组织）不进指标格，写进结论句下的元信息行。
5. **面板不加框**：标题 15 / 600 ＋ 一道墨线 ＋ 右侧“去… →”；面板之间 32 留白（§3），8 列网格列距 40。
6. **尺寸线与引线**：差值画成带端点的尺寸线，数字写在线上；结论里的数字用细引线连到证据点。关系类对象（人员任职、任教）用时间线。
7. **斜纹只表示“还没有”**：同色斜纹 ＝ 未达成、剩余；墨斜纹 ＝ 没有数据（待接入、未提供）。
8. **纸只给纸**：答卷、原卷、试卷版面用白纸、双层细阴影、宋体；教师、学生、资料不画在纸上。
9. **身份**：曜彩三色只在对象内页签右端一处；40px 网格底代替标尺。内容末尾不设收尾行和墨线（PO 2026-11-06 取消）。

**停用**：标尺 1–8 / A–D、SHEET 号、黑底字母块（A / B / C / D）、纸面套框（≥ 2 层）、“返回 ＋ × ＋ 沉浸阅读”多出口、把左栏换成同级名单、模态里放内容预览、处理栏里同样大小的一排灰按钮。

### 0 一句话

**墨线只画结构，内容不加框；先给结论；曜彩做面，文字用字色；实色是已经发生，斜纹是还没有。**

### 1 原则

1. **结构和内容分开。** 墨线围出少量大块，块里的内容用浅线、留白和底色组织。
2. **结论先行。** 每页先给一句结论或当前状态，再放证据面板。一个面板只回答一个问题。
3. **颜色有意义。** 一种颜色在全站只表达一种意思，并且不单独表意，要配文字、符号或线型。
4. **字不压原色。** 曜彩原色只做没有文字的面和标记。
5. **斜纹表示“还没有”。** 实色表示已经发生；斜纹表示对照、剩余、未达成、没有数据。
6. **只换视觉。** 主题适配不改结构和几何（沿用 P107）。

### 2 线条与框

### 2.1 线条三级

| 级别 | 样式 | 只用于 |
|---|---|---|
| L1 结构线 | 1.5px `--line` | 页面主分区（顶栏底、左栏右、右栏卡片外框）、面板外框、面板标题下沿、标题栏（`bp-titleblock`）外框、主按钮 |
| L2 分隔线 | 1px `--border` | 面板内的行分隔、表格行、标题栏内格、输入框和下拉的默认边、次按钮、提示框（`bp-callout`）、浅色说明卡 |
| L3 无线 | 底色或留白 | 列表项、chip、状态签、记录条目；选中态用 `--accent` 底加左侧 2px 墨线 |

### 2.2 嵌套和标题

- **框最多两层**：页面主分区 → 面板。面板里不再出现 L1 框；卡片嵌在卡片里时，内层降为 L2 或去框。
- **一个标题一道线**：面板标题只用底边一道 L1。`BpSectionCard titleRule` 的尾线停用（P106 修订，见 §12）。
- **虚线只用于分组**，不做行分隔。

### 3 标识与强调

| 元素 | 规则 |
|---|---|
| 面板编号块 | 每个面板一个，放在标题左侧。无归属的页面用墨底白字；有责任方的页面用角色字色底白字（§4.4）。一屏不超过 4 个 |
| 图纸大字母、SHEET 号、刻度尺、双框 | 只用于画板和对外材料封面（§7），工作页不用 |
| 主按钮 | 墨底白字，硬阴影 3px 曜蓝 `#339FF2`。一屏一个主按钮 |
| 次按钮、筛选、输入 | L2 边，白底，无阴影 |
| 危险按钮 | 红字，L2 红边 `#E3B3B3`，放在最后，先确认 |
| 状态签 | 不加边框（§4.3） |

### 4 智能曜彩

### 4.1 三色三级

| | 原色：无字的面和标记 | 字色：文字和细线 | 浅底：大面积底 |
|---|---|---|---|
| 曜蓝 | `#339FF2` | `#0F5FA8`（白 6.52 · 浅底 5.67） | `#E3F1FD` |
| 曜紫红 | `#E0438F` | `#A8245C`（白 6.84 · 浅底 5.77） | `#FCE6F0` |
| 曜青绿 | `#C2F25B` | `#3F6309`（白 7.00 · 浅底 6.46） | `#EEFBD3` |

夜图：
- 字色用 曜蓝 `#5BB4F5`（7.57）、曜紫红 `#F48BBA`（7.53）、曜青绿 `#C2F25B`（13.15）；
- 原色可以直接做面；
- 夜图浅底的取值留到 U2 浏览器验收时定（§13 Q5）。

### 4.2 一色一义

| 颜色 | 意思 | 用在 |
|---|---|---|
| 曜蓝 | 数据、AI、可操作 | 图表主系列、链接（字色）、主按钮硬阴影、进行中、AI 来源（配文字） |
| 曜紫红 | 需要人处理 | 待确认、优先处理、受阻、新情境、低于预期 |
| 曜青绿 | 完成、确认、正向 | 已确认、高于预期、补回、荧光笔 |
| 红 `#C62828` | 错误、危险 | 真正的错误、危险操作；不和曜紫红混用 |
| 灰 | 中性、待定 | 待实施、未开始、继续观察 |

### 4.3 文字和颜色

- **字不压原色**：色块、柱、点、色带、色签前的小方块用原色；文字一律用字色级，放在白底或浅底上。所有文字对比度 ≥ 4.5，目标 ≥ 5.5。
- **状态签**：浅底加字色的药丸，无边框。一行最多一个状态签。
- **荧光笔**：曜青绿原色色带衬在墨字下面（墨字 13.65）。只用在结论句和图表注释里，一屏 1–3 处。
- **签名色带**：顶栏下一条 3px 三色带；标识前三色竖条。三色并排只出现在这里和对外材料封面。
- 不用渐变，不发光。AI 来源的三色渐变沿用现行规则，只用于真实 AI 来源，并配文字。

### 4.4 角色色

用于有责任方的页面（教研项目、学校决定、教师确认这类）：
- 教研对应曜蓝，学校对应曜紫红，教师对应曜青绿；
- 面板编号块用对应字色底加白字；
- 角色签用浅底加字色，前面放原色小方块；
- 进度条已完成部分用原色，剩余部分用同色斜纹。

无归属的页面不使用角色色。

### 4.5 用量

- 面积（截图像素）：中性色 ≥ 85%；曜彩原色和浅底合计 ≤ 10%；荧光笔和强调 ≤ 5%。U0 鲜明版实测约 3%。
- 颜色多不代表重要。一屏里最醒目的应当是结论句和主按钮。

### 5 斜纹

| 斜纹 | 意思 |
|---|---|
| 墨斜纹（`#4B5260` 线 / 白底） | 对照值、剩余、没有数据 |
| 曜紫红斜纹（字色线 / 浅底） | 未达成、未补回、低于预期、优先处理区 |
| 曜蓝斜纹 | 计划中、待批阅；教研侧未完成 |
| 曜青绿斜纹 | 待确认的达成；教师侧未完成 |

- 规格：135°，线宽 1.5px，间距 6px；斜纹块加 1px 墨框；SVG 用同参数的 `pattern`。
- **斜纹上不放字**，标签放在旁边，或加白色描边。
- 常用位置：
  - 进度条、指标条的剩余和未达成部分；
  - 对比条中的对照组（源站做法）；
  - 图表里低于预期的区间、优先处理区；
  - 没有数据的周期；
  - “数据不足”分组。

### 6 版式

| 项 | 规则 |
|---|---|
| 结论 | 页首一句，22px / 600，放在浅底说明卡里（L2 边，3px 曜蓝左条）；下一行灰字写依据和“看依据 →” |
| 面板 | 一屏 2–4 个；一个面板一个问题；内容多就拆页或折叠 |
| 字号 | 正文 14–15px；数值 KPI 30px 等宽；13px 及以下只用于注释、元信息和表头，占比 ≤ 55% |
| 等宽字 | 只给数字、编号、坐标；中文值用无衬线 |
| 宽度 | 内容最大 1120（含右栏页 1000），沿用高分辨率规则（AP22） |

### 7 装饰按场景

| 场景 | 网格纸 | 双框＋刻度尺＋SHEET 号 | 斜纹 | 签名色带 |
|---|---|---|---|---|
| 工作台页面 | 页面底，透明度降到 .045 | 不用 | 用（§5） | 顶栏一条 |
| 预览框架 | 按冻结规定 | 按冻结规定 | 用 | 不加 |
| 画板 | 页面底 | 每张图纸一次 | 用 | 可用 |
| 对外材料（PPT、印刷） | 不用 | 封面一次 | 用在图表里 | 封面、章节页用大色块 |
| 长文（规范、说明） | 不用 | 不用 | 不用 | 不用；用阅读版式 |

对外材料的“印刷版式”（白底、线宽按印刷换算、字号和留白加大、一页一图）在 U5 另出样张和说明。

### 8 图表

- 实际值：曜蓝字色线（2–2.2px）加原色数据点（1px 墨描边）；可加曜蓝浅底面。
- 预期、对照：灰虚线，或墨斜纹条。
- 关注项：曜紫红；正向：曜青绿面加墨描边。曜青绿不做细线。
- 数值标签：墨字加 4px 白描边，压在色块上也清楚。
- 不靠颜色单独区分系列，要同时配形状或线型（方、菱、圆、虚线）。
