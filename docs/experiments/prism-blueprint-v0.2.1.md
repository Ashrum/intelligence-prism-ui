## 本轮依据

Product Owner 对照原始 `OLE_Prism_Blueprint_Experiment_v0.1.html` 后，接受三项精修建议：恢复真实原稿对照、恢复工作区与三栏关系、调整摘要和输入区域的密度。仍以 **C｜轻量 Blueprint** 为唯一设计方向，保留真实 coss / Prism 组件的外观和行为。

上一轮的主要偏差来自页面构成：常驻站点侧栏使 1366px 桌面提前落入两栏布局；顶部摘要和默认表单占比偏大；移除连续轴线后，C 的区域关系变得不明显。页内“v0.1 C · 结构复现”使用的是同一套当前组件，不能代替真实原稿。原稿默认 Paper，站点则继承用户主题，比较条件也不相同。

这些判断来自原稿和组件源码、容器宽度及 CSS 推导，未将它们当作浏览器截图证据。

## 实现边界与复用

- 只调整实验路由的页面组合及其独立画布入口，不更改其他页面的导航布局。
- 使用既有局部主题作用域，默认 Paper；不写全局主题属性或浏览器主题偏好。
- 保持固定事实：42 道题、36 份作答、39 道已关联试题、3 项待复核、第 3 / 4 步快照、7 / 9 章节框架，以及原会话和七类详情。
- 延续 v0.2 已记录的 coss（含 particles）与 Beautiful UI 检索。现有 Card、ToggleGroup、Button、Badge、Dialog、Progress、AgentMark、AgentTaskProgress、AgentMessage、AgentComposer 可覆盖本轮；输入区通过已有公开属性组合。
- 不修改 `components/coss/**`、全局 Token、组件 API、组件目录、依赖、业务数据或 Agent Runtime。
- 按已批准的 Site-first 实验流程先更新既有 Site，再通过独立 PR 同步 GitHub；未通过 Product Owner 视觉审核前，不升级为正式页面规范。
