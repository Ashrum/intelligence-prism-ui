## 真实画面与问题

本轮依据 Product Owner 提供的两张 v0.3 Paper 截图进行集中精修：`CleanShot 2026-10-13 at 14.27.42@2x.png`（2048 × 1660）和 `CleanShot 2026-10-13 at 14.28.11@2x.png`（2048 × 486）。截图已实际读取；未将图片上传到公开站点或仓库。图片像素尺寸不代表 CSS 视口宽度，不能据此推断缩放或其他断点的表现。

独立截图审核收敛为三项问题：右栏证据条目标题与来源重叠；顶部重复说明压低任务主画面；48px 区域编号块和两行图签的视觉分量偏重。整体双图框、四边尺带和淡网格已经形成明确的 Blueprint 识别，本轮保留。

## 前后对照

| 部分 | v0.3 真实画面 | v0.4 精修 |
| --- | --- | --- |
| 待复核证据 | 两行文字被桌面端固定按钮高度压住，相邻条目相互侵入 | 使用现有 Prism Button 的 `navigation` 尺寸，以内容自然撑开高度，保留标题、来源、图标和详情入口 |
| 页面层级 | 实验大标题、设计方向、来源简介和两段提示常驻，任务标题被推到下方 | 评审控件集中在紧凑工具区，实验说明默认折叠；任务标题成为主标题 |
| 工程标记与图签 | 48px 字母块、较高标题区、两行元数据图签占据较多注意力 | 32px 字母块及更紧的标题区；宽容器下图签单行，窄容器按字段重排，保留证据链和全部四项元数据 |

证据重叠的原因是 coss Button 默认尺寸包含 `sm:h-8`，页面原有 `h-auto` 不能取消这个响应式固定高度。现有 Prism `size="navigation"` 会取消默认尺寸并提供自适应内容高度，因此无需修改组件源码、提高 CSS 优先级或缩小文字。

继续复用现有 Button、Collapsible、Card、Badge、ToggleGroup、Dialog、Progress 及 Agent 展示组件；本轮没有新增通用组件需求。保留既有版本对照、原稿新窗口入口、局部三主题、专注查看、七类详情和输入反馈。原稿模式仍提示原始 HTML 只支持 Light / Paper；切换不改组件库主题偏好。
