## 参考与内容基线

参考材料为 `OLE_Prism_Blueprint_Experiment_v0.1.html`，选定 C 方案。原参考是独立 HTML，以手写样式模拟组件；本轮接入仓库真实组件。

保留原演示的任务语境、静态事实和详情：高二数学函数与导数单元、42 道题、36 份作答、39 道已关联试题、3 项待复核、7 / 9 个报告章节框架，以及任务进程、会话、证据与产出三组内容。固定示例不调用模型或后端，不由点击推进任务状态，不生成最终诊断。

窄屏始终保留 3 项待复核、当前步骤和 4 步总数；可去除装饰标记，不沿用原 HTML 在部分宽度隐藏待复核统计的做法。按内容容器宽度重排，避免站点导航挤占宽度后仍强制三列。

页内的“v0.1 C · 结构复现”与“v0.2 · 精修”复用同一数据与组件，只切换页面外层构成。结构复现仅覆盖工作纸面；原稿外部应用栏和导航由现有组件站 `Shell` 承接，不复刻虚拟学校顶栏。它用于在真实组件条件下控制内容和控件变量，不是原 HTML 的像素级复刻。

- 通用控件先检索现有 coss，包含 particles 的 Dialog、Tabs、Badge 和 Input 组合；本页只组合已有控件，不复制或修改固定来源文件。

- 字号按 `docs/typography.md`；三色品牌与 AI 来源按 `docs/foundation-tokens.md`，不将品牌三色当作可靠性或正确性编码。

## 实验交互

- 结构对照：默认 v0.2，可原位切换 v0.1 C 结构，主题由站点右上角切换。
- 详情查看：任务、记录、三项证据、报告结构、数据来源共七种固定内容；复用 Dialog 并声明关闭后返回触发按钮。
- 输入反馈：接收并清空演示输入，显示固定说明；不追加任务事实，不推进步骤，不调用服务。
- 专注查看：收起实验介绍和精修观察，保留结构切换与退出入口；Escape 退出，弹窗打开时由 Dialog 处理 Escape。
- 流程状态：使用既有 `snapshot` 模式，并明确标注“固定演示快照 · 第 3 / 4 步”。

上述为已实现行为，实际浏览器交互尚待下述验收。
