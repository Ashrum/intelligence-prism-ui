# Typography v0.2.1 · 实施验证候选

站内入口：`/next/foundations/typography`。此规范经本轮实施授权应用于组件页和业务演示；Windows / Apple 真机字形与 iOS 聚焦行为仍需核对。不是整站无障碍认证。

## 字号角色

根字号 `100%`，默认 16px。字号以 rem 定义，行高采用无单位比例；颜色与尺寸分离。界面只使用 400 / 500 / 600 三档字重。主题与任务状态不改变文字角色的尺寸；空间不足时换行或滚动，不缩字。

| Token | 默认字号 / 行高 | 字重 | 角色 |
| --- | --- | --- | --- |
| page-title | 26 / 36 | 600 | 页面主标题、Agent 欢迎标题 |
| section-title | 20 / 30 | 600 | 主要分区、完整任务弹窗 |
| block-title | 16 / 24 | 600 | 独立阅读、核对、编辑模块 |
| item-title | 14 / 20 | 600 | 同一集合中的重复条目标题 |
| read-body | 16 / 28 | 400 | 题干、解析、完整回复、长文本编辑 |
| ui-body | 14 / 20 | 400 | 短界面内容、表格数值、短属性输入 |
| ui-action | 14 / 20 | 500 | 按钮、导航、菜单、字段标签 |
| ui-hint | 14 / 22 | 400 | 字段说明、错误、任务状态、样本与分母 |
| ui-meta | 12 / 18 | 400 | 低优先级时间戳与来源编号 |
| component-label | 12 / 16 | 500 | 非关键短徽标、快捷键 |
| stat-display | 24 / 32 | 600 | 少量概览指标 |

`item-title` 按集合条目身份判定，即使条目包含正文或操作；独立工作模块使用 `block-title`。卡片宽度不是判定依据。完整题干不能因位于卡片中降为 14px。

题干阅读与编辑必须同为 16/28。控件沿用 coss 现有 sm 断点（40rem / 默认 640px）：窄屏短输入与主要操作文字为 16px；长编辑区各宽度均为 16/28。页面不自行新增字体断点。此实现不能代替 iOS Safari 实机聚焦验证。

指标使用 `tabular-nums` 数字特性，保留 UI 字体；负号、小数点、百分号与主数值同为 24px，其他单位使用 `ui-body`（14/20/400），基线对齐并留 .25rem 间隙。组件的 value 可用 ReactNode 传入数值与单位，不靠切换等宽字体实现对齐。

## 字体、语言与数学

界面栈：`-apple-system, BlinkMacSystemFont, "Segoe UI", "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", "Noto Sans CJK SC", sans-serif`。中文文档 `lang="zh-CN"`，外语材料单独声明语言。Windows 500 与 400 可能呈现相同字形，层次必须同时依靠字号、位置、留白和分组。保留 `font-synthesis:none`，不将真实字形支持假定为已验证。

界面字距为 0，不以中文斜体或全大写标签制造层级。数学变量的语义斜体和英文格式工具演示不受此限制。阅读段落约束为最多 40em；容器可以更宽以容纳图表或公式。

现有 MathML 与本地 STIX Two Math 保持原渲染路径；`.prism-math` 的 1.125em 光学校准及独立显示公式度量由公共数学样式管理。公式可自然撑高，不能把 28px 行高误当作固定裁剪高度，不能把上下标硬性放到 12px。打印中的 pt、mm 和图形 SVG 的内部字形坐标遵守各自排版语义。

## 颜色与组件适配

普通文字、附属信息、占位说明、单位均检查实际合成背景下 4.5:1；大号文字按 WCAG 对应门槛检查。禁用态和图片/Canvas 另外记录，不冒充已通过。

浅色 `muted-foreground` 使用 #4B5563；在 #F4F5F7 上约 6.93:1。旧 #6B7280 在该背景约 4.43:1，不能继续用于普通小字。暖纸和深色使用各自主题 Token，不能硬编码浅色修正值。启用的 placeholder、未选中 tab、可选跨月日期不再以 72% 透明度降低文本对比。

公共适配位于 `app/(next)/next/typography.css`，由 `theme.css` 导入。54 个 `components/coss` 文件及其来源 manifest 不改。Prism Badge 默认使用 lg，状态文字保持 14/20；12px 短标签须显式选择 `text-component-label`，且不得单独承载决策。所有 Textarea 为长内容角色，短属性应使用 Input。

## 工程与验证边界

`lib/prism-next/typography.ts` 是站内角色说明；Tailwind v4 的 `@theme` 提供同名 `text-*` utility。业务代码不使用 text-xs / text-sm / 任意数值字号。`scripts/check-typography.mjs` 随每次验证构建执行，阻止回退到局部字号；例外仅限物理打印设置、图形内字和图表轴标签。真实图表刻度保持 12px，决策说明和数据表使用至少 14px。

浏览器检查覆盖全站路由的默认显示状态，并对阅读/编辑、任务状态、字段错误、弹窗和窄屏控件做代表性交互。字体页记录实际完成的范围；未穷举所有组合状态。MathML、SVG/Canvas 图形内容、打印纸面和禁用控件分别处理，不能将常规 DOM 文字的检查结果扩展成这些场景的自动认证。

横向布局须分别记录页面意外溢出、组件内关键步骤或操作被遮挡、以及表格/公式/原稿的必要局部滚动。组件 scrollWidth > clientWidth 是人工复核线索，不一律视为失败。关键流程须直接显示当前步骤与总步骤，完整列表可展开；不得缩小字体来适应容器。
