## 复用检索与取舍

读取 Supervisor 缓存 `audit/registry.json`（579 项）及 particles：`p-group-11`、`p-combobox-10`、`p-combobox-8`、`p-tabs-14`、`p-tabs-10`、`p-select-20`、`p-toolbar-1`、`p-meter-3`、`p-frame-1`；复核固定 coss Button、Select、Tabs、Combobox、Toolbar、Frame、Meter、Tooltip、Badge，以及冻结稿、ReviewTools 与 DocumentRegionViewer 源码。

- 直接 import 冻结稿 `paper-review.css` 的外壳、三栏、响应式、看片台、侧签、沉浸与 reduced-motion；import `dockPaperToolbar`、`railBand`、`railCollapsedForWidth` 及最佳宽度常量；import `ReviewTools` 完整复用浮动评审工具。未抽取或改变共享模块。

- DocumentRegionViewer 用于纸上评分点命中与整张作答命中；关闭其选中值驱动定位，由宿主可见页与显式定位控制，避免手动滚动时被选中纸反向拉回。其既有文档命中区域尺寸属于文档坐标，不新增 coss 控件尺寸覆盖。
- 本任务是通用文档预览宿主，不涉及 Agent 执行或复制 Beautiful UI，因此不采用 Beautiful UI。PaperPreview 仍为单页协议，不能直接承担连续题目页与 36 份作答。

## 逐区实现

1. 56px 单行顶栏：题号、题目与知识点身份、副标题、分组题目跳转、全班得分率、导出意图与快捷键 Dialog。返回题目列表同样发出宿主意图；本设计稿没有独立业务列表路由。
2. 左栏：题目 / 知识点两个视角，真实计数筛选。小题四列题号格、解答题行、类型得分率、页标与高失分概览。中性 / warning / destructive 均读夹具给定字段；知识点专题分组、证据不足标记、展开证据清单。↑↓ 选择当前筛选条目，Enter 定位，滚入可视区。默认栏宽、收起、焦点恢复、1440 分档继承冻结稿，独立键 `prism-question-review-rail-collapsed-best/compact`。
3. 画布：题目页始终保留，之后为 36 份作答；筛选全部 / 失分 / 待复核。题目页含题面、Q17 椭圆图、标准答案、评分点与知识点；证据点击以 `ring-info` 标出精确评分点。作答纸蓝字、红批注、纸外首字头像/姓名/考号/分数状态；当前纸原对比和选中环，其余纸不透明度 65%。默认适合宽度，题目页回到顶部；无扫描仅替换作答纸图像，题目与检查器事实仍可看。
4. 56px 贴纸侧签（Q2）：仅缩放/适合/旋转、版本与标注、沉浸，回题目和学生导航移至顶部学生控制条；所有操作 Tooltip + Kbd，沿用默认/icon，不覆盖控件宽高。
5. 检查器：本题全班分布 / Q01 选项条、评分点量值与知识点入口；知识点模式替换上半为概况和证据。下半跟随当前作答，评分点缺失原因缩进、教师确认事实、AI 来源细线与未知置信度、查看整卷。唯一主按钮为“教师批阅”，另有“更正评分”，都只显示“已请求”。待复核记录明确写“评分依据待教师确认”。
6. 浮动 ReviewTools：视口、主题、无扫描、恢复题目栏默认、按钮归位、返回组件库；没有顶部评审控制条。框架占满视口，窄屏沿用题目/作答/检查器分区。主数字严格两处，其余量值使用语义正文角色。

## Q4 · 数据分析规划与自适应作答（2026-10-02）

本节取代 Q1/Q2 的逐生客观题纸张、默认全部筛选及检查器统计呈现。三栏各回答一个问题：左栏“哪些题出了问题”；检查器上半（加题目页）“这道题错在哪”；中间“谁错了、怎么错的”。同一数据只在一处作为主信息出现：左栏以逐题率和问题定位为主，题目页保留题面/答案/评分依据，检查器承载完整统计，中间承载错误分组和个人作答证据。

### 复用与口径

- 重新检索 Supervisor 缓存 registry 的 `collapsible` / `p-collapsible-1`、Select、Group，阅读 particles `p-select-20`、`p-group-11`、`p-tabs-10` 及固定 coss Collapsible 源码。原生 Collapsible 的受控展开、标准 Button trigger 已满足名单和满分纸折叠，沿用 Select `size="sm"`、Tabs `size="sm"`、Badge、Avatar 和现有 ThinBar；不复制 particle 的尺寸覆盖。不新增组件目录条目、公开 API、依赖、视觉令牌；通用评审宿主不涉及 Agent 执行，不采用 Beautiful UI。
- `analysis.ts` 是宿主纯函数：输入逐生作答与全卷总分，输出统计事实、评语、排序和答案分组；`fixture.ts` 先固定逐生作答，再求各题汇总，组件仅呈现。全卷总分为同一学生 20 题得分之和，不使用原六人另一个口径的整卷总分。
- `rate`：客观题为完全答对人数 / 36（标签“正确率”），主观题为平均分 / 满分（标签“得分率”），百分比四舍五入到整数。均值与总体标准差各保留一位小数；标准差用未经舍入的均值计算，分母为 36。
- 高低分组按全卷总分降序，各取 `Math.round(36 × 0.27) = 10` 人；同分按学生 ID 排序保证确定性。D = 高组逐题总分 / (10 × 满分) − 低组逐题总分 / (10 × 满分)，呈现两位小数，评语按未舍入 D 判定：≥0.40 优秀、≥0.30 良好、≥0.20 尚可、<0.20 待改进。此为常用经验标准，可由业务调整；负区分度照实呈现，不截为零。
- 满分率/零分率保留一位小数；待复核数按作答 review 字段计数，受影响人数为未得满分人数。选择题逐项提供人数、整数占比、高低组人数；主要干扰项取错误选项中人数最多者，同数按字母顺序择一。填空题由确定性 `answerText` 归类，缺失显示“未提供”，分组纸退化为答错学生名单。
- 主观题评分点率从逐生评分点得分求和计算；原因人数按包含该原因的学生去重，标为“AI 归纳”，不增加三色线。三色线只保留在当前作答的“AI 判定依据”。知识点仍按既有证据事实展示，不推断长期掌握度。
- Q17 保留 47%、6/19/11、待复核 2、30 人失分、张雨桐 6/12；Q01 保留 A31/B2/C1/D2、86%。原有各题 rate/分布无调整。新计算 Q17 平均 5.6、总体标准差 4.2、D=-0.525（显示 -0.53、待改进），来自既有逐生分配与全卷排名，未为了评语修改得分；补齐其余选择题的确定性选项与填空答案归类。

### 三栏与交互

- 左栏四列题号格始终显示每题百分比，题号沿用 `text-ui-action`（500）与 tabular-nums；风险底色由宿主给定，待改进小题加 info 圆点。Tooltip/aria-label 包含题号、题型、率、均分、区分度和评语。题型标题含题数，整段率为次要信息。默认按题号恢复答题卡；另外两种排序统一用行列表，键盘与可见排序一致。顶栏题目跳转行增加率标签与区分度。
- 检查器上半“本题分析”以定义列表呈现四组量值，选择题展示干扰项与高低组，填空题展示答对/答错和典型错误答案，主观题展示分布、评分点和 AI 原因；关联知识点只去重显示一次。未选人时下半不渲染；选中后才显示当前作答，因此主数字位置最多两处（未选人一处、选人两处），唯一主按钮仍为“教师批阅”。
- 客观题仅题目纸、作答分组纸；错误按人数降序、正确组默认折叠。默认“答错”，导航、刻度、快捷键只在该集合内；展开正确组会同步切为“全部”，切回答错会收起正确组。点击姓名后，仅增加该生的一张裁切纸及查看整卷入口，检查器和控制条同步。填空错误组还提供代表性裁切图；缺扫描时使用等高占位。
- 主观题默认“失分”，Tabs 顺序为失分 / 待复核 / 全部；待复核 → 零分 → 部分得分排列。“全部”的满分名单以 Collapsible 概括，展开后才渲染满分作答纸；导航直接选中满分学生时同步展开。收起正在查看的满分组会清除当前学生并定位折叠行。切题恢复该题默认筛选与未选人状态。
