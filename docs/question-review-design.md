# 题目与知识点预览框架 · Q1 设计稿

评审页 `/next/reviews/question-review`，仅为设计稿宿主，不进组件目录、不接入业务 Store 或真实服务。冻结基线为 `paper-review-design-v1.0` / `7887fac`；冻结稿说明 `docs/paper-review-design.md` 保持原文。正式视觉验收由 Supervisor 执行。

## 复用检索与取舍

读取 Supervisor 缓存 `audit/registry.json`（579 项）及 particles：`p-group-11`、`p-combobox-10`、`p-combobox-8`、`p-tabs-14`、`p-tabs-10`、`p-select-20`、`p-toolbar-1`、`p-meter-3`、`p-frame-1`；复核固定 coss Button、Select、Tabs、Combobox、Toolbar、Frame、Meter、Tooltip、Badge，以及冻结稿、ReviewTools 与 DocumentRegionViewer 源码。

- Group / Combobox 直接承接两类跳转，使用原生搜索、分组、选中标记、键盘和关闭焦点返回。Tabs 使用 `size="sm"` 与 Badge，Select 用标准 `size="sm"`。不复制 particles 的局部字号、控件高度或业务数据。
- 直接 import 冻结稿 `paper-review.css` 的外壳、三栏、响应式、看片台、侧签、沉浸与 reduced-motion；import `dockPaperToolbar`、`railBand`、`railCollapsedForWidth` 及最佳宽度常量；import `ReviewTools` 完整复用浮动评审工具。未抽取或改变共享模块。
- 连续画布在本地 `question-paper-canvas.tsx` 沿用冻结稿的缩放、旋转、滚动可见页、拖动、双指手势与锚点计算，增加纸外学生标注和整张作答纸聚光。保留局部复制，避免为页眉槽与聚光改动冻结稿模块；后续共同组件化时再合并。
- DocumentRegionViewer 用于纸上评分点命中与整张作答命中；关闭其选中值驱动定位，由宿主可见页与显式定位控制，避免手动滚动时被选中纸反向拉回。其既有文档命中区域尺寸属于文档坐标，不新增 coss 控件尺寸覆盖。
- 本任务是通用文档预览宿主，不涉及 Agent 执行或复制 Beautiful UI，因此不采用 Beautiful UI。PaperPreview 仍为单页协议，不能直接承担连续题目页与 36 份作答。

## 逐区实现

1. 56px 单行顶栏：题号、题目与知识点身份、副标题、分组题目跳转、全班得分率、导出意图与快捷键 Dialog。返回题目列表同样发出宿主意图；本设计稿没有独立业务列表路由。
2. 左栏：题目 / 知识点两个视角，真实计数筛选。小题四列题号格、解答题行、类型得分率、页标与高失分概览。中性 / warning / destructive 均读夹具给定字段；知识点专题分组、证据不足标记、展开证据清单。↑↓ 选择当前筛选条目，Enter 定位，滚入可视区。默认栏宽、收起、焦点恢复、1440 分档继承冻结稿，独立键 `prism-question-review-rail-collapsed-best/compact`。
3. 画布：题目页始终保留，之后为 36 份作答；筛选全部 / 失分 / 待复核。题目页含题面、Q17 椭圆图、标准答案、评分点与知识点；证据点击以 `ring-info` 标出精确评分点。作答纸蓝字、红批注、纸外首字头像/姓名/考号/分数状态；当前纸原对比和选中环，其余纸不透明度 65%。默认适合宽度，题目页回到顶部；无扫描仅替换作答纸图像，题目与检查器事实仍可看。
4. 56px 贴纸侧签：回题目、学生上一位/跳转/下一位、缩放/适合/旋转、版本与标注、沉浸；所有操作 Tooltip + Kbd。中间人数按钮采用 coss `size="sm"`，其余沿用默认/icon；不覆盖控件宽高。
5. 检查器：本题全班分布 / Q01 选项条、评分点量值与知识点入口；知识点模式替换上半为概况和证据。下半跟随当前作答，评分点缺失原因缩进、教师确认事实、AI 来源细线与未知置信度、查看整卷。唯一主按钮为“教师批阅”，另有“更正评分”，都只显示“已请求”。待复核记录明确写“评分依据待教师确认”。
6. 浮动 ReviewTools：视口、主题、无扫描、恢复题目栏默认、按钮归位、返回组件库；没有顶部评审控制条。框架占满视口，窄屏沿用题目/作答/检查器分区。主数字严格两处，其余量值使用语义正文角色。

## 夹具与参照修正

`fixture.ts` 为确定性宿主事实：36 人、20 题、18 个知识点；题目筛选 20/8/12/6、知识点筛选 18/6/12/6。每题分布合计 36，逐生评分点合计等于得分，全班得分平均四舍五入为标示得分率；选项人数与逐生选择一致。保留指定 Q17 的 47%、6/19/11、30/36、待复核 2、张雨桐 6/12，Q01 A31/B2/C1/D2 与 86%，原六位学生姓名和 OLE ID，以及原六个知识点的名称、专题、得分率、受影响人数和证据分值。

- 5174 只列 6 题、6 个知识点、6 位学生，列表标题总量与实际条目数不一致；本稿补齐其余条目，以统计测试为依据。
- 椭圆参照答案 `a²=4,b²=1` 不满足 P(2,1)。本稿按原题设校正为 `a²=8,b²=2`、焦点 `(±√6,0)`；示意图按这一条件绘制。未修改只读来源或冻结稿默认题面。
- 椭圆知识点原记录写“18 分 · 3 道证据题”却只列 12/17：补第 14 题评分点 1；证据为 Q12 点 1、2（8 分）、Q17 点 2（4 分）、Q14 点 1（6 分），合计 18。
- 导数保留 Q6/Q16 共 4 个评分点、20 分；参数 8 分、线面垂直 12 分、条件概率 16 分、充分必要条件 10 分。其他题分值由补齐夹具给定，不将原六人整卷总分套用到补齐后各题明细。
- 5174 Q01“选 A”与“逆命题错误”及部分给分相冲突；这里 A 明确为正确选项“充分不必要条件”，31 人满分、5 人零分，不延用其固定给分函数。

## 冻结稿与双向跳转

冻结页唯一新增可见内容为“班级对比”标题内的标准 link Button“看全班此题 →”。增加 URL 参数读取，默认 URL 无参数时事实、布局与渲染保持原样。参数 `question`、`student` 校验后选题/选生；从 Q1 进入时附 `source=question-review`，通过本地 `paper-link.ts` 提供 36 人的确定性全卷事实与图像，整卷和单题的身份、题号、逐题分数一致。原冻结稿 6 人夹具与 5174 同一编号存在不同姓名，因此从冻结默认名册出发按唯一姓名解析 Q1 ID，避免误选同号不同人。

新增的名册输入仅为 `examples/paper-review` 内部 StudentPanel 参数，不是组件库公开 API。修改前已捕获默认 SSR（移除 ReviewTools 宿主、标准化 React 生成 ID）；测试移除新增链接后与 `tests/fixtures/paper-review-v1.sha256` 完全比对。未抽取共享模块、未改冻结稿 CSS/fixture/连续画布、未改原始 coss、依赖、Foundations 或目录。
